# Synthetic companion files

These small English text files accompany `../inspection-complex.json`. Every outcome is fabricated for learning project organization. They do not describe a real aircraft, flight, launch, battery test, supplier approval or manufacturing qualification.

Use this directory as a disposable example project root. Copy the manifest into the root as `project.json`, then generate folder-creation and verification scripts in Open ESKD. The files supplied here match selected relative references only. The check report should still list missing controlled drawings, supplier records and software artifacts. That is intentional: example metadata cannot supply real controlled engineering documents.

No MP4, JPEG, firmware binary, CAD model, fabrication archive or supplier certificate is included. Paths ending in `.placeholder.mp4` or `.placeholder.jpg` are optional placeholders, never recordings or completed approvals. A present file is not evidence of engineering acceptance.

Keep the `synthetic` labels when copying these fixtures. Replace them with properly identified real evidence only through your organization's review and configuration process.
